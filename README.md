# 🚀 Drive2Tube AutoPoster — Google Drive to YouTube, Facebook & TikTok

**Drive2Tube AutoPoster** হলো একটি আধুনিক ও শক্তিশালী ভিডিও অটোমেশন স্টুডিও। এর মাধ্যমে আপনার **Google Drive** ফোল্ডার থেকে হাজার হাজার ভিডিও স্বয়ংক্রিয়ভাবে লোড করে সরাসরি একাধিক **YouTube Channels (Shorts)**, **Facebook Pages (Reels)** এবং **TikTok Accounts**-এ একটার পর একটা স্বয়ংক্রিয়ভাবে পোস্ট ও শিডিউল করা যায়।

---

## 🌟 মূল ফিচারসমূহ:

1. **📁 গুগল ড্রাইভ ইন্টিগ্রেশন (৫০০০+ ভিডিও সাপোর্ট):**
   - যেকোনো গুগল ড্রাইভ পাবলিক ফোল্ডারের লিংক দিয়ে নিমেষেই সব ভিডিও লোড।
   - অটোমেটিক টাইটেল অপটিমাইজেশন, ডিউরেশন ডিটেকশন ও থাম্বনেইল প্রিভিউ।
   - ৬০ সেকেন্ডের কম ভিডিওগুলোর জন্য অটো `#Shorts` ও `#Reels` ফরম্যাট তৈরি।

2. **🌐 মাল্টি-প্ল্যাটফর্ম সোশ্যাল মিডিয়া সাপোর্ট:**
   - **🔴 YouTube Channels:** YouTube Shorts অটো-পোস্টিং (YouTube Data API v3)।
   - **🔵 Facebook Pages:** Facebook Reels লাইভ পোস্টিং (Meta Graph API v19.0) ও ১-ক্লিক মেটা বিজনেস স্যুট পাবলিশার।
   - **⚫ TikTok:** টিকটক রিলস অটো-ডিস্ট্রিবিউশন।

3. **🔄 স্মার্ট পোস্টিং মোড:**
   - **Cross-Posting Mode:** একটি ভিডিও সব সিলেক্টেড প্ল্যাটফর্মে একযোগে পোস্ট হবে।
   - **Round-Robin Mode:** প্রথম ভিডিও ইউটিউবে, দ্বিতীয়টি ফেসবুকে, তৃতীয়টি টিকটকে এভাবে পালাক্রমে ডিস্ট্রিবিউট হবে।

4. **⏱️ কাস্টম সিডিউল ব্যবধান (Interval Delay):**
   - সাথে সাথে (Immediate) অথবা প্রতি ৫ মিনিট, ৩০ মিনিট, ১ ঘণ্টা বা প্রতিদিন নির্দিষ্ট সংখ্যায় পোস্ট করার সুযোগ।

5. **📟 লাইভ আপলোড কনসোল ও রিয়েল-টাইম লগ:**
   - প্রতিটি ভিডিও আপলোডের রিয়েল-টাইম অগ্রগতি (% প্রগ্রেস) দেখা যায়।
   - প্রতিটি সফল আপলোডের পর সাথে সাথে সরাসরি ফেসবুক, ইউটিউব ও টিকটক লিংক প্রদর্শন।

## 💻 কীভাবে চালাবেন (Local Setup):

1. রিপোজিটরিটি ক্লোন করুন:
   ```bash
   git clone https://github.com/mdnahid7653959-spec/drive2tube-autoposter.git
   cd drive2tube-autoposter
   ```

2. সার্ভার চালু করুন:
   ```bash
   node server.js
   ```
   অথবা উইন্ডোজে `run.bat` ফাইলে ডাবল ক্লিক করুন।

3. ব্রাউজারে প্রবেশ করুন:
   ```
   http://localhost:3000
   ```
